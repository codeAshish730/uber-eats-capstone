# Uber Eats Operational & Customer Intelligence System

## Project Overview

This project uses synthetic food-delivery data to explore operational performance and customer behaviour using data analysis and machine learning.

## Datasets

The project includes seven datasets:
- Customers
- Restaurants
- Drivers
- Orders
- Deliveries
- Reviews
- Payments

The CSV files are stored in `data/raw/`.

## Technologies

- Python
- Pandas
- Faker
- Scikit-learn (planned)
- Git

## Project Structure

- `data/raw/` — synthetic CSV datasets
- `data/processed/` — cleaned datasets
- `src/` — Python scripts
- `notebooks/` — analysis notebooks
- `reports/` — project findings and figures
- `models/` — saved models

## Data Disclaimer

All data is synthetically generated for educational purposes and does not represent actual Uber Eats customer or operational records.
